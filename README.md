# TypoRacer

TypoRacer is a typing-speed and computer-aptitude practice project. It includes a native Windows desktop application written in C++ with Win32/GDI, plus a standalone browser-based version.

## Project versions

- **Windows desktop app** — C++14, Win32 API and GDI rendering.
- **Browser version** — standalone `index.html`; open it in a modern browser or publish the repository with GitHub Pages.

## Features

- Timed typing tests and performance summaries
- WPM, CPM and accuracy metrics
- Automated ghost-racing opponent with selectable speed levels
- Keyboard visualisation and finger-placement guidance
- Performance graph and weak-key diagnostics
- General prose, code, numbers/symbols, survival and custom-text practice modes
- Procedural typing sounds (desktop version)
- Session history and personal bests (desktop version)
- HTML aptitude certificate export/sample
- Standalone browser interface

Runtime files such as `scores.dat`, `history.csv` and the compiled executable are intentionally not tracked. The desktop app creates its data files when needed.

## Run the browser version

1. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
2. The browser version is a standalone HTML file; it does not require a backend server.
3. For a hosted version, enable GitHub Pages for this repository and use the `main` branch and `/(root)` folder.

The sample `Typing_Aptitude_Certificate.html` is kept at the repository root because the browser page opens it using a relative path.

## Build the Windows desktop version

### Requirements

- Windows 10 or Windows 11
- MinGW-w64 with `g++` available on `PATH`

### Build and launch

Double-click `build.bat` from File Explorer, or open Command Prompt/PowerShell in the repository folder and run:

```bat
build.bat
```

To compile manually from the repository root:

```bat
g++ -std=c++14 -O2 -mwindows -o TypoRacer.exe src/main.cpp src/TypingTest.cpp -lgdi32 -lcomctl32 -luser32 -lwinmm
```

The native desktop version uses Windows-specific APIs and will not compile as a native Windows GUI app on Linux or macOS without a compatible Windows cross-compilation toolchain.

## Performance metrics

The desktop app reports typing metrics such as words per minute (WPM), characters per minute (CPM), accuracy and consistency. The app's performance tiers are project-defined labels, not population percentiles or a formal certification standard.

## Data and privacy

- `scores.dat` and `history.csv` are local runtime data files generated by the desktop app.
- These runtime files are excluded from Git so personal test history and local records are not committed accidentally.
- No compiled `.exe` is included; build it locally using the instructions above.

## Troubleshooting

- **'g++' is not recognized:** install MinGW-w64 and add its `bin` directory to your Windows `PATH`.
- **Build fails on missing Windows headers/libraries:** run the build on Windows with a working MinGW-w64 installation.
- **Certificate doesn't open in the browser version:** keep `index.html` and `Typing_Aptitude_Certificate.html` together in the repository root.
- **Data files appear after running the desktop app:** this is expected; they are local runtime files and are ignored by Git.
